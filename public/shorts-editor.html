① 파일 올리기 — 영상 + 사진 함께

          
왼쪽 위 동그란 점선 박스를 누르면 파일 선택창이 열립니다. 영상(MP4·MOV·WebM)과 사진(JPG·PNG·WEBP)을 함께 골라도 됩니다.

          
    
            
  • 영상 3~5개가 가장 자연스럽습니다. 사진도 한 컷처럼 붙는데, 사진은 기본 4~5초에 살짝 줌인(켄번스)됩니다.
    • 
            
  • 처음 써 볼 때는 상단 ✨ 데모 체험을 누르면 샘플 프로젝트로 바로 익힐 수 있습니다.
    • 
            
  • 드래그 앤 드롭도 됩니다(PC 브라우저). 폰에서는 파일 선택 버튼을 쓰세요.
    • 
          

        


        

          
② AI 스토리 · 후킹 자동 생성

          
스토리 방향에 한 문장만 적고(예: “주말 카페 투어 브이로그 톤으로”), 톤·자막 스타일을 고른 뒤 🧠 Gemini로 영상 분석 & 스토리·메타 생성을 누르세요.

          
    
            
  • 영상은 앞부분·중간·끝 프레임을 뽑아서 AI가 읽습니다 — 없는 가게 이름·가격은 지어내지 않습니다.
    • 
            
  • 결과로 컷 타임라인 · 유튜브 제목 · 설명 · 해시태그가 한 번에 깔립니다.
    • 
            
  • 오른쪽 🎯 AI 추천 후킹 3안(호기심형·직설형·반전형)을 누르면 화면 상단 타이틀이 바로 바뀝니다.
    • 
          

        


        

          
③ 컷 편집 — 좌우 크롭 · 자르기 · 다시쓰기 · 성우 속도

          
오른쪽 타임라인 세그먼트 편집에서 컷마다 직접 손볼 수 있습니다.

          
    
            
  • 가로 영상 좌·우 위치: 슬라이더를 밀면 9:16 안에서 피사체를 가운데로 맞출 수 있습니다.
    • 
            
  • 시작·끝(초): 영상에서 쓸 구간을 초 단위로 직접 지정합니다. 배속과 함께 즉시 프리뷰에 반영됩니다.
    • 
            
  • ✨ AI 다시쓰기: 마음에 안 드는 한 컷의 대본·자막만 다시 씁니다.
    • 
            
  • 성우 속도: 1.0x ~ 1.3x. 왼쪽 채널 프리셋 · 볼륨 카드에서 전역으로, 컷 카드에서 컷별로 바꿀 수 있고, 컷 길이도 음성 길이에 맞춰 자동 조정됩니다.
    • 
            
  • 성우 생성을 누르면 무료 서버 성우(MP3)가 입혀지고 단어별 강조 타이밍이 맞춰집니다.
    • 
            
  • 🩹 원본 자막 가리기(프리뷰 아래): 영상에 이미 박힌 자막을 블러 / 다크 밴드 / 확대 밀기로 덮습니다. 컷 카드의 원본 자막 가리기 드롭다운으로 컷마다 예외를 두고, 내가 얹는 새 자막 배경은 옆의 자막 배경 가림막에서 따로 고르면 됩니다.
    • 
          

        


        

          
④ 내보내기 — MP4/WebM + SRT + 업로드 세트

          
상단 내보내기 버튼을 누르면 세 가지 방법이 나옵니다.

          
    
            
  • 방법 1 · 바로 녹화: 영상 길이만큼 실시간으로 그려서 저장합니다(진행률 % 표시). MP4가 되면 .mp4, 안 되면 .webm으로 저장됩니다.
    • 
            
  • 방법 3 · .srt 자막: 컷 타임라인 기준 자막 파일을 받아 캡컷·유튜브 스튜디오에 올리면 자막을 다시 손볼 수 있습니다.
    • 
            
  • 📋 유튜브 업로드 세트 복사: 오른쪽 유튜브 제목·태그 탭에서 제목·설명·해시태그·고정 댓글을 한 번에 복사합니다.
    • 
          

        


        

          
💡 아이디어로 제작 탭 — 글만 주면 5컷 쇼츠

          
상단 탭에서 💡 아이디어로 제작을 누르면 왼쪽이 아이디어 전용 화면으로 바뀝니다. 오른쪽 9:16 프리뷰·자막·성우·BGM·내보내기는 그대로 함께 씁니다.

          
    
            
  • 1. 스토리보드 — 아이디어 한 줄(예: “월요일마다 커피가 간절한 이유”)을 적고 장르·화풍·주인공 외형을 고른 뒤 버튼을 누르면 5컷 대사·자막·그림 프롬프트가 깔립니다.
    • 
            
  • ⚡ 주제 추천 — “오늘 뭐 찍지?” 싶으면 누르세요. 조회수가 나올 만한 주제 3안을 눌러 바로 넣을 수 있습니다.
    • 
            
  • 🔗 링크 → 5컷 — 뉴스·블로그 링크는 본문, 유튜브 링크는 자막을 읽어 참고 자료로 씁니다.
    • 
            
  • 2. 그림 생성 — 무료 Pollinations가 기본입니다. 실패하면 같은 컷을 내장 모션그래픽으로 보여 줍니다(빈 화면 없음).
    • 
            
  • 3. 성우 — 대화 모드(A 여성 · B 남성)로 자동 교차되고, 무음 자동 제거로 컷 길이가 말소리에 맞춰집니다.
    • 
            
  • 🎨 다시 그리기 — 컷 카드의 수정 요청칸에 “더 밝게”, “비 오는 밤”처럼 쓰고 누르면 그 컷만 다시 그립니다.
    • 
            
  • 📊 카드 컷 — 숫자·비교 컷은 그림 대신 선명한 인포그래픽 카드로 그립니다(체크로 직접 바꿀 수 있음).
    • 
            
  • 🎥 카메라 모션 — 줌인·줌아웃·좌우 패닝·임팩트 흔들림을 컷마다 고를 수 있습니다.
    • 
            
  • ➡️ 편집기로 — 아이디어 컷을 그대로 타임라인에 두고 내 사진·영상을 추가하면 뒤에 이어 붙습니다.
    • 
            
  • 🔁 루프 연결 1초 — 마지막 1초 → 첫 1초를 이어 재생해 무한 루프가 자연스러운지 확인합니다.
    • 
            
  • 📌 시리즈 · 💾 프로젝트 — 시리즈는 장르·화풍·연출 설정을, 프로젝트는 대본·그림까지 여러 개 저장·불러오기합니다.
    • 
            
  • 📱 실제 UI — 프리뷰 위에 유튜브·릴스 버튼과 제목을 엎어 보여 줍니다. 자막이 버튼에 가리는지 확인용이고, 녹화 파일에는 들어가지 않습니다.
